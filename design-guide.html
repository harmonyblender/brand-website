01

디자인 원칙

01

Typography First

시각적 장식을 최소화하고 텍스트 자체의 배치와 크기, 무게감으로 위계를 만든다. 이미지보다 텍스트가 먼저 읽힌다.

02

Radical Whitespace

콘텐츠 밀도를 의도적으로 낮추고, 여백이 레이아웃의 구성 요소로 기능한다. 빈 공간이 브랜드 자신감을 표현한다.

03

Monochrome Base

흑·백·회색의 스펙트럼만으로 전체 UI를 구성한다. 액센트 컬러 없음. 색이 아닌 공간과 무게로 강조한다.

04

Editorial Grid

잡지식 편집 레이아웃. 콘텐츠를 열(column)로 정렬하고, 수평선(border)이 섹션 구분의 주요 도구다.

05

List as Design

프로젝트 목록을 단순한 테이블 형식으로 표현한다. 카드·썸네일 없이 텍스트 행의 반복 자체가 시각적 리듬을 만든다.

06

Quiet Interaction

애니메이션은 없거나 최소화. 호버는 밑줄 또는 배경색 미세 변화로만 처리. 인터랙션이 시선을 분산시키지 않는다.

내 포트폴리오 적용 포인트

현재 내 포트폴리오 → 개선 방향

Hero 폰트 크기
현재: 7rem 대형 디스플레이 타입
Studio Apt 방식: 15px 보통 크기 본문 → 텍스트 자체로 승부
→ 큰 Hero를 유지하되 font-weight 300으로 가볍게
프로젝트 갤러리
현재: 카드 + 호버 오버레이
Studio Apt 방식: 텍스트 행 목록
→ 이미지 중심 갤러리 + 리스트 뷰 토글 추가 고려
스킬 섹션 배경
현재: 검정 배경 (dark section)
Studio Apt 방식: 단일 배경 (흰색 유지)
→ 배경 전환 제거하고 선(border)으로만 구분

Studio Apt에서 차용할 요소

Works 테이블 형식
프로젝트명 | 카테고리 | 연도 3열 구조로 목록 섹션 추가. 스크롤 시 리듬감.
Border-based 구분
박스·그림자 대신 border-bottom 1px solid로 섹션과 행 구분. 더 깔끔하고 편집적.
Eyebrow 레이블
10px uppercase letter-spacing 0.2em 섹션 레이블. 이미 적용 중이나 더 강화 가능.
모노크롬 강화
현재 Hero, Skills 섹션의 검정 배경 제거하고 흰 배경 단일화. 더 편집지 느낌.
